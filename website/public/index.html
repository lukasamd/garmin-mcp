PRZEWODNIK WDROŻENIA

Uruchom własny serwer.

Potrzebujesz kont Garmin Connect i Cloudflare, komputera z przeglądarką, terminala oraz konta w wybranym asystencie. Poniższa ścieżka korzysta z Cloudflare. Nazwy opcji w panelach mogą się zmienić.

Koszty: serwer jest przeznaczony do użytku w Cloudflare Free, ale ten plan ma limity. Dostępność własnych MCP w asystentach zależy od konta, kraju i planu. Sprawdź warunki przed rozpoczęciem.
1. Zainstaluj narzędzia i przygotuj projekt

Wybierz swój system. Potrzebujesz Git, Node.js 26 z npm oraz pnpm 12.16.1. W nowszych wersjach Node.js Corepack nie jest instalowany automatycznie, dlatego poniżej instalujemy pnpm osobno.

Windows
  1. Pobierz i zainstaluj Git for Windows dla swojej architektury (zwykle x64). Pozostaw domyślne ustawienia instalatora.
  2. Pobierz Node.js 26: instalator Windows (.msi), x64 albo ARM64 zgodnie z komputerem. Zainstaluj go z npm.
  3. Zamknij i ponownie otwórz Wiersz polecenia: naciśnij klawisz Windows, wpisz cmd i wybierz aplikację. Sprawdź instalację:
git --version
node --version
npm --version

Wynik Node powinien zaczynać się od v26.. Jeśli widzisz komunikat, że polecenie nie istnieje, otwórz nowe okno terminala i sprawdź instalację.

Zainstaluj pnpm:

npm install --global pnpm@12.16.1
pnpm --version
macOS
  1. Otwórz Terminal (naciśnij Command + Spacja i wpisz Terminal). Wpisz git --version. Jeżeli macOS zaproponuje instalację narzędzi wiersza poleceń, zatwierdź ją i ponów polecenie. Możesz też użyć xcode-select --install.
  2. Pobierz Node.js 26 dla macOS jako instalator (.pkg), odpowiedni dla komputera, i zainstaluj go wraz z npm.
  3. Zamknij i ponownie otwórz Terminal. Sprawdź wersje i zainstaluj pnpm:
git --version
node --version
npm --version
npm install --global pnpm@12.16.1
pnpm --version

Wersja Node powinna zaczynać się od v26.. Jeśli instalacja globalna zwróci błąd uprawnień, skorzystaj z alternatywnych sposobów instalacji pnpm albo poproś agenta o pomoc; nie uruchamiaj poleceń z uprawnieniami administratora bez zrozumienia ich działania.

Linux

Otwórz terminal. Zainstaluj Git menedżerem pakietów swojej dystrybucji, jeśli go nie masz:

# Ubuntu / Debian:
sudo apt update && sudo apt install git curl
# Fedora:
sudo dnf install git curl
# Arch / CachyOS:
sudo pacman -S git curl

Wykonaj tylko polecenie dla swojej dystrybucji. Jeśli nie masz Node.js 26, możesz zainstalować menedżer wersji nvm według jego instrukcji. Po instalacji otwórz nowy terminal i wpisz:

nvm install 26
nvm use 26
node --version
npm --version
npm install --global pnpm@12.16.1
pnpm --version

Wersja Node powinna zaczynać się od v26.. nvm instaluje Node w katalogu użytkownika, dzięki czemu instalacja pnpm zwykle nie wymaga sudo. W dystrybucji z własnym aktualnym Node.js 26 możesz użyć innego sprawdzonego sposobu instalacji.

Następnie we wszystkich systemach, w tym samym terminalu:

git clone https://github.com/lukasamd/garmin-mcp.git
cd garmin-mcp
pnpm install --frozen-lockfile
pnpm check
pnpm wrangler login

Otworzy się logowanie Cloudflare. Zaloguj się samodzielnie i zatwierdź dostęp. Jeśli polecenie nie działa, skorzystaj z promptu dla agenta poniżej.

2. Utwórz Workera i zabezpiecz autoryzację
  1. W panelu Cloudflare przejdź do Workers & Pages. Jeśli nie masz subdomeny workers.dev, skonfiguruj ją. Utwórz Worker garmin-mcp z szablonu „Hello World”.
  2. Zapisz jego adres: garmin-mcp.TWOJA-SUBDOMENA.workers.dev.
  3. Otwórz Cloudflare Zero Trust. Przy pierwszym uruchomieniu wybierz plan Free i utwórz zespół.
  4. W Access → Applications dodaj aplikację typu Self-hosted. Wybierz adres Workera oraz ścieżkę /authorize. Dodaj regułę Allow → Emails z Twoim adresem e-mail; wybierz logowanie jednorazowym kodem (One-time PIN).
  5. W prywatnym oknie przeglądarki otwórz adres Workera z dopiskiem /authorize. Przed stroną Workera powinien pojawić się ekran Cloudflare Access. Jeśli nie, popraw regułę.
  6. W szczegółach aplikacji Access znajdź Application Audience (AUD) Tag.

Chroń ścieżkę /authorize, nie cały Worker: klient MCP musi dotrzeć do /mcp i endpointów OAuth. Na chronionej stronie możesz zatwierdzić klienta po sprawdzeniu jego nazwy i adresu.

3. Utwórz klucz i zapisz sekrety
  1. W terminalu projektu wpisz pnpm wrangler secret put ACCESS_AUD. Wklej AUD dopiero w odpowiedzi na ukryty monit i zatwierdź.
  2. Zaloguj się do Garmin Connect → Personal API, utwórz klucz, zapoznaj się z warunkami i wybierz jego ważność. Klucz jest wyświetlany tylko raz.
  3. W terminalu wpisz pnpm wrangler secret put GARMIN_API_KEY. Wklej klucz dopiero w odpowiedzi na ukryty monit i zatwierdź. Nie dopisuj go do polecenia.

Jeśli masz już aktywny klucz Personal API, sprawdź skutki jego zastąpienia dla innych połączeń. Traktuj klucz jak hasło.

4. Wdróż i przetestuj

W tym samym katalogu uruchom:

pnpm wrangler deploy

Jeśli Wrangler zapyta o utworzenie KV, potwierdź. Skopiuj adres swojego Workera i dopisz /mcp. Sprawdź, czy bez logowania endpoint odrzuca żądanie:

curl -sS -o /dev/null -w 'HTTP %{http_code}\n' https://TWOJ-WORKER.workers.dev/mcp

Oczekiwane: HTTP 401. Sam ten wynik nie potwierdza poprawności pozostałych zabezpieczeń. Po podłączeniu klienta sprawdź również odczyt aktywności, snu i HRV.

5. Podłącz asystenta

ChatGPT: w Plugins wybierz dodanie własnego serwera MCP, wklej adres kończący się na /mcp, wybierz OAuth i przejdź autoryzację. Dostępność opcji może zależeć od konta. Nasz test z kontem Plus w Work zakończył się powodzeniem.

Claude: w Connectors wybierz dodanie własnego konektora, wpisz adres MCP i przejdź autoryzację. Anthropic podaje dostępność również w planie Free, z limitem jednego własnego konektora. Przed rozpoczęciem sprawdź aktualne wymagania.

Gemini: dostępność własnych aplikacji MCP jest ograniczona. Google opisuje obecnie m.in. wymaganie przebywania w USA, konto osobiste i język angielski; sprawdź bieżące warunki. Gemini CLI jest osobnym narzędziem. Zgodność tych klientów z tą konfiguracją wymaga testu.

Podczas autoryzacji sprawdź nazwę aplikacji i adres docelowy na stronie zgody. Po zmianie listy narzędzi może być wymagane jej odświeżenie lub rozpoczęcie nowej rozmowy.

DOBRZE WIEDZIEĆ

Najczęstsze pytania.

Czy muszę płacić?

Projekt jest open source. Cloudflare oferuje plan Free z limitami; dostępność konta i warunki usług mogą się zmieniać. Asystent może mieć własne ograniczenia lub wymagać odpowiedniego planu. Duże pliki FIT mogą przekroczyć limity darmowego Workera.

Czy mogę użyć czegoś innego niż Cloudflare?

Istnieją lokalne serwery MCP i rozwiązania uruchamiane w Dockerze. Ten projekt jest jednak oparty na Workers, Cloudflare KV i Access; przeniesienie go wymaga zmian w kodzie i zabezpieczeniach. Nie przedstawiamy jeszcze innej ścieżki jako przetestowanej.

Jak odłączyć dostęp albo wymienić klucz?

Odłącz aplikację w wybranym asystencie. Klucz Garmin możesz usunąć w ustawieniach Personal API, co unieważnia powiązane tokeny Garmin. Nowy klucz wpisz poleceniem pnpm wrangler secret put GARMIN_API_KEY. Aby unieważnić wszystkich klientów OAuth tego Workera, wyczyść jego namespace KV — ponowna autoryzacja będzie potrzebna wszystkim klientom. Nie usuwaj innych zasobów KV.

Czy AI widzi Training Readiness?

Ten serwer udostępnia tylko dane obsługiwane przez jego narzędzia. VO₂ max może być dostępne, jeśli Garmin zwróci dane. Bezpośredniego odczytu Training Readiness obecny serwer nie wystawia; analiza snu i HRV nie jest jego dokładnym odpowiednikiem.
